Retrain workflow
  1. python scripts/train_baseline.py — trains on CIC-IDS2017 BENIGN flows and writes model, scaler, schema, and score calibration.

  3. python scripts/evaluate_model.py — benchmarks at the tuned threshold (updates this page).
  4. Set ML_ANOMALY_THRESHOLD in .env and restart the app.
